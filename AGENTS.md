# Working in Super Agent

- Run `pnpm browser:install` after installing dependencies or updating Playwright, then run `pnpm check` before opening a pull request.
- Capture named views with `pnpm screenshot --view <name> --width phone|desktop --out <dir>` as described in the [development standard](docs/development-standard.md).
- See the [design](docs/design.md) and [decisions](docs/decisions.md) for the enforced rules and their rationale.
